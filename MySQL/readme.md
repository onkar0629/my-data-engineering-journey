# 📖 About

This section is part of my **Data Engineering Journey** repository.

The goal of this SQL course is not just to learn SQL syntax, but to understand how SQL is used in real-world applications and modern Data Engineering.

Unlike traditional SQL notes, this repository focuses on:

- Understanding concepts from first principles
- Learning through practical examples
- Solving real business problems
- Preparing for Data Engineering interviews
- Building strong SQL fundamentals
