# Day 01 — Introduction to MySQL

## 📚 Topics Covered

- What is SQL?
- What is MySQL?
- SQL vs MySQL
- Database and DBMS
- Relational Database Management System (RDBMS)
- Tables, rows, and columns
- MySQL use cases in Data Engineering

## 🎯 Learning Goals

By the end of this session, I should be able to:

- Explain SQL and MySQL in simple terms.
- Understand how relational databases organize data.
- Identify databases, tables, rows, and columns.
- Explain why MySQL is useful for Data Engineering.

## 🧠 Key Takeaways

> SQL is the language used to communicate with relational databases.
>
> MySQL is a relational database management system that uses SQL.

## 💡 Data Engineering Connection

MySQL is commonly used as an OLTP/source database. A Data Engineer may extract data from MySQL, transform it, and load it into a data warehouse or data lake for analytics.
